kishizu

Declare the season. Watch the episodes. Stop thinking about it.

› Add a show

Name it as animeschedule.net lists it, or use whatever you'd search Nyaa for. Max episodes is the season length — 0 if unknown.

› Train a show

Pick a show and the episode you want to teach it. kishizu searches Nyaa and asks you to confirm which release is that episode.

› Grade a release

Paste a Nyaa link or release title. Pick the show and episode, then mark each part good, acceptable or wrong.
