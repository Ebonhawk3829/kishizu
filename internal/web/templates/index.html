› Add a show

Two ways to add a show, both anchored to the schedule: paste the show's animeschedule.net URL, or pick it from the season list. The page is fetched on add, so the season length, cover art and every alternative name are filled in for you.

› Adopt a finished season

For a season that has already finished, adopt a release from releases.moe (SeaDex) instead of tracking it week by week. You pick which file is which episode, then kishizu downloads and files it like any other episode.

Browse this season

Every show on the season, from a cached snapshot. The filter matches the romaji name, the English name and the slug, whichever is displayed.

Train

Releases found by searching every alias, most informative first. Confirm a parse and the list reorders — when nothing new remains, there is nothing left to teach.

Adopt a finished season

Paste a releases.moe (SeaDex) entry URL. kishizu reads the release, lists every file in it, and proposes which are episodes.
